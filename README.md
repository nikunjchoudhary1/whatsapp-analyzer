# ChatStory — WhatsApp Chat Analyzer

AI-powered WhatsApp chat analysis. Works in English, Hindi & Hinglish.

## Local Setup

1. Install dependencies:
   ```
   npm install
   ```

2. Create a `.env` file:
   ```
   GEMINI_API_KEY=your_key_here
   ```

3. Run locally:
   ```
   npm start
   ```
   Open http://localhost:3000
